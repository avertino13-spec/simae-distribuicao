# SIMAE — canal de distribuição

Este repositório **não contém código-fonte**. Serve apenas para os servidores SIMAE
instalados nos clientes obterem:

- `versao.json` — a última versão publicada (assinada digitalmente pelo autor);
- `licencas/<ID-da-instalação>.lic` — licenças renovadas (assinadas, presas a cada instalação);
- os instaladores, anexados às *Releases*.

Um ficheiro alterado ou com assinatura inválida é recusado pelos servidores.
